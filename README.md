# godot - dodge the creeps

My output from Godot engine [Your first 2D game](https://docs.godotengine.org/en/stable/getting_started/first_2d_game) tutorial

# Usage

- Requires [godot](https://godotengine.org/download)

```
git clone https://github.com/andrealbinop/godot-dodge-the-creeps.git
cd godot-dodge-the-creeps
godot .
```
